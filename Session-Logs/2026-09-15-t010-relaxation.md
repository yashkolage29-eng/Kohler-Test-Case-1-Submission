  paths and the alternatives route reuse the EXACT pipeline;
  full-validator-on-every-output holds by construction.
- `relax/diagnose.ts` — fail-cause tracing (OPT §10.2.1): typed solver infeasibility →
  deduped causes with rule id + category + verbatim blocker + narration-safe
  explanation; measured minimum gaps: budget deficit (minViableCost − B_max) and
  per-key C2 shrink headroom (600→530 etc.).

  release — substitutes are already in every binding pool, so this is the only real
  pool-widening lever), shrink-clearance (C2 → minLegal, config-scoped clone),
  drop-class (most expensive taste-required class), raise-budget (B_max → measured
  minViableCost), move-door (deterministic full-wall mirror). Each path generated only
  when its lever can measurably move; inputs cloned, never mutated.

  re-searched via solvePlan, deduped by plan id, bounded `MAX_RELAXATION_PLANS = 3`,
  else out-of-scope with the traced final blocker + measured min viable cost.

  invalid-input bypass the menu (input repair ≠ relaxation). Behavior change: an
  ultra-low budget brief now yields a raise-budget menu instead of T-009's direct
  out-of-scope (supersedes per ADR-027; OPT §13.3's out-of-scope now = exhausted
  relaxation).

- Tests: `relax/relax.test.ts` — 16 tests (raise-budget/shrink-clearance/drop-class
